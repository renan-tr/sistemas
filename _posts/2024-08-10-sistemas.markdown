## Sistema

Um sistema físico é a interconexão de componentes, dispositivos ou subsistemas.
Pode ser visto como um processo no qual as entradas são transformadas pelo sistema ou fazem com que o sistema responda de alguma forma.

Em sistemas de tempo contínuo, a entrada é composta por sinais contínuos resultando também em um sinal contínuo.
De forma similar, um sistema discreto transforma um sinal de entrada discreto em um de saída também discreto.

## Propriedades Básicas de Sistemas

### Memória

- Um sistema não possui memória se sua saída para cada valor da variável independente em um determinado instante depende **apenas** da entrada no mesmo instante.

Por exemplo, um resistor é um sistema sem memória.

Já um acumulador seria exemplo de um sistema discrete com memória. De forma análoga, um capacitor é um sistema contínuo com memória.

Assim, o conceito de memória corresponde a presença de um mecanismo no sistema que retém informação sobre os valores de entrada de outro instante além do atual.
Em sistemas físicos, isso está associado com o aramzenamento de energia.

### Invertibilidade

Um sistema é invertível se entradas distintas levam a saídas distintas.
Se um sistema é invertível, então existe um sistema inverso que, quando colocado em cascata com o original resulta na entrada do primeiro sistema, como ilustrado na figura a seguir.

### Estabilidade

É uma importante propriedade do sistema, sendo que em um sistema estável pequenas entradas levam a respostas que não divergem.
Por exemplo, o pêndulo da figura é um sistema estável. Se for aplicada uma força, haverá um deslocamento horizontal. Entretanto, devido a força da gravidade, o pêndulo tende a voltar a posição vertical.
Já para o pêndulo invertido, aa gravidade tende a aumentar o desvio em relação a vertical, de forma que uma pequena força aplicada leva a um grande deslocamento. Assim, o pêndulo invertido é instável.

![Pêndulo](https://renan-tr.github.io/sistemas/assets/img/pendulo.png)

### Invariância no tempo

Um sistema é invariante no tempo se o comportamento dele é fixo ao longo do tempo.
Por exemplo, um circuito RC é invariante no tempo se os valores de R e C foram constantes ao longo do tempo, uma vez que seriam esperados os mesmos resultados se um mesmo experimento fosse repetido em diferentes dias.

De outra forma, um sistema é invariante no tempo se um deslocamento no sinal de entrada resultar em um mesmo deslocamento no sinal de saída.

### Linearidade

Um sistema linear é aquele que possui a propriedade da superposição. Neste caso, se a entrada consistir de uma soma ponderada de diversos sinais, a saída é a superposição (soma ponderada) das respostas do sistema a cada um dos sinais.

Assim, um sistema é linear se:

- A resposta para x1(t)+x2(t) for y1(t)+y2(2).
- A resposta para a.x1(t) for a.y1(t), onde a é uma constante.

A primeira corresponde à propriedade da aditividade enquanto a segunda seria a homogeneidade.
